# ✖️⭕✖️⭕Tic_Tac_Toe✖️⭕✖️⭕
A simple Tic-Tac-Toe game built to practice JavaScript, game logic, and interactive UI

# ⚙️Technologies
- css
- html
- js(JavaScript)

# 📔What does it do?
- Played by 2 players
- Players take turns marking one empty box
- Get 3 marks in a row to win
- Win horizontally, vertically, or diagonally
- share

While building this project, I practiced:

- DOM manipulation
- Event handling
- Working with arrays and conditions
- Creating an interactive UI with HTML and CSS
- Debugging and problem-solving
